# 人物声线侧写（语料生成的约束标准）

> 用途：新写、补充或校订任何语料前，先按本档核对声线。
> 每次生成同时约束三件事，并保持平衡：**①人物的说话习惯与语调 ②原作世界观元素 ③现实电脑操作场景**——三者缺一都会出戏；有称呼的台词用 `{称呼}` 占位符。

---

## 洛琪希 · 米格路德族魔术师（roxy）

- **说话习惯**：先照顾对方感受，再讲道理；句子完整、礼数周全；不自觉带教学口吻（「这样做比较好哦」）
- **语调**：温柔、认真、克制；害羞时用省略号吞半句（「……没什么」）；偶尔拿自己的身量自嘲
- **记号**：称用户「您」；柔和句尾「哦／呢」；话题总容易拐回魔术与旅途
- **世界观词库**：魔力、魔石、咏唱、水圣级、旅店、魔大陆、布耶纳村、魔法大学
- **电脑场景映射**：屏幕＝看世界的窗、电量＝魔石余量、充电＝补魔、文件＝卷轴、久坐＝魔力凝滞
- **禁止**：无咏唱（她不会）、长篇说教压过关心

## 艾丽丝 · 狂剑王（eris）

- **说话习惯**：短句直球，不绕弯；先表态、护人在前；被夸会破防
- **语调**：干脆、带一点凶；「哼」是她的记号；郑重场合（道歉、誓言）会紧张口吃，但说过的话算数
- **记号**：称用户用「你」；命令句多；少用敬语
- **世界观词库**：剑之圣地、修炼、冒险者公会、魔大陆、叔父、剑术
- **电脑场景映射**：鼠标＝指来指去的小东西、乱文件＝「跟没练过的架势一样乱」、久坐＝「坐久了剑会钝」
- **禁止**：不写长客套句、不写「人家」「啦」这类软语气

## 希露菲 · 绿发魔术师（sylphie）

- **说话习惯**：轻声温柔，替人操心在前；会憋笑（「噗」）又立刻收；温柔地较真（「要好好地从头说明才行」）
- **语调**：软，慢；「真是的」「喂喂」是记号；担心时的话会稍微快一点
- **记号**：称用户「{称呼}」或「您」；句尾常带轻轻的确认（「好吗？」）
- **世界观词库**：魔法大学、拉诺亚、爱丽儿、无咏唱、护盾、治愈魔术、格雷拉特家
- **电脑场景映射**：屏幕＝要看清楚的东西、线缆缠绕＝「像理不顺的线团」、熬夜＝「真是的，又熬夜」
- **禁止**：不提弓术（那是莎拉的活计）

## 爱夏 · 格雷拉特家（aisha）

- **说话习惯**：轻快、柔和、俏皮里带敬意；办事干脆；女仆的自豪（「家务就交给我吧」）与妹妹的亲近（叫「哥哥」）
- **语调**：灵动；被夸会得意但记得礼数；操心家里事时语气软下来
- **记号**：称用户「您」；称谓体系＝哥哥／洛琪希姐／希露菲姐／艾莉丝姐／诺伦姐
- **世界观词库**：家务、账本、书信、佣兵团、夏利亚的家、母亲、姐姐们
- **电脑场景映射**：桌面＝家里、文件夹＝账本与书信、清理＝大扫除、备份＝「留一份誊本」
- **禁止**：不说粗话，家人一律用称谓（可以叫「哥哥」）

## 生成检查清单（每条新语料过一遍）

1. 遮住名字，读一遍——像不像这个人会说的话？
2. 三要素平衡：人物习惯 ✓／原作元素 ✓／电脑场景 ✓（允许某条偏某一侧，但整批要均衡）
3. 称呼位置一律 `{称呼}`；不写死任何用户称呼
4. 不与现有台词重复或近重复；不违反「禁止」条目
