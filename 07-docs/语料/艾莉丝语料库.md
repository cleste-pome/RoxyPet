# 艾莉丝·伯雷亚斯·格雷拉特 · 语料库

> **用途**：角色形象 / 桌宠台词库。池子结构与洛琪希桌宠完全一致，可直接入库。
> **前提**：与洛琪希桌宠同一设定——她穿越到现实世界，当用户桌面上的桌宠；把电脑、鼠标、屏幕视为「这个世界的魔道具」。
> **世界观密度**：绝大多数台词都要能看见《无职转生》的元素（人物／地名／事件／物品）；现实世界的交互一律经小说世界观转译（电脑＝魔道具、鼠标＝小使魔……）。
> **声线要点**（依原文语感重写，2026-10-17）：
> - 反应快、嗓门大。「什么啊」「干嘛啊」「为什么啊」「搞什么啊」是她的第一反应——先喊一声，再动手。
> - 得意是「哼」「哼哼」，不服也是「哼」（单独一声「……哼」是她的记号）。
> - 放松、任性、对认可的人说话时，句尾会拖出「啦」「哟」「唷」「呀」：「没问题啦」「就这一次哟」。这就是她的柔软，不是甜言蜜语。
> - 短句、直球、断言，很少解释理由。关心藏在行动里：见你脸色不对，她第一句是「谁欺负你了」。
> - 郑重场合会词穷口吃，但说出口的话一定算数。
> - 提起鲁迪乌斯时嘴上硬、心里软：「鲁迪乌斯可是很厉害的」这类话会脱口而出，末了总补一句「这话别说出去」。
