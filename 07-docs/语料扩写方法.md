# 语料扩写方法（实战记录 · 2026-10-17）

> **这份文件是干什么的**：把「怎么把语料从几百条扩到上千条、还不跑偏」这件事完整记下来——包括流程、四个角色的声线档案（带原作依据）、以及这一路踩过的坑。下次要**扩写语料**、**修某一池**、或者**加一个新角色**，照着这份做就行。
> 相关文件：[语料位置](语料/语料位置.md)（格式与转换规则）、[语料修正提示词](语料修正提示词.md)（交给外部 AI 用的提示词）、[人物声线侧写](语料/人物声线侧写.md)（简版约束）。

---

## 一、先记住三条铁律

1. **仓库里的 md 是唯一稿源**。改台词只改 `07-docs/语料/<人物>.md`，JSON 由脚本生成，**永远不要手改 JSON**。
2. **写完必须跑一次**：`python3 03-scripts/import-speech.py`（构建时 `build.sh` 也会自动跑）。改完不跑，程序读到的还是旧台词。
3. **一次别让一个写手（人或 agent）写超过 40 条**。超过这个量，回复会撞单次输出的上限（实测 16384 token），整批作废——2026-10-17 有 7 个 agent 就是这么废掉的。

## 二、扩写流程（这次的实际做法）

```
① 定缺口   把四人（或目标角色）的池子形状对齐成同一个模板，算出每个池缺几条
② 定形状   模板：闲聊 360 ／ 情境每档 20 ／ 摸头 50·拖动 35·注视 35·寂寞 35 ／
           方向每档 12 ／ 系统九项各 10~12      → 每人约 800 条
③ 分片     一个写手一个片：闲聊按主题拆 3~4 片（身体／电脑世界／原作情结／情绪），
           情境+系统各一片。每片 ≤40 条，片与片主题不重叠
④ 写作     给我（或外部 AI、或 agent）这些：角色声线卡 + 硬性要求 + 现有全部台词清单
⑤ 机器四查 字数≤40 ／ 文件内完全重复 ／ 批内重复 ／ 跨角色完全重复 + 近似重复
⑥ 终审     一个 agent 通读全文，只挑「出戏 / 重复 / 超字数 / 网络腔」，返回该删的条 + 理由
⑦ 回填     按清单删改 → 跑 import → 重算表头统计 → 重编译发布
```

**分片主题怎么切**（避免同质化）：同一批里如果都写「催睡觉」，结果就是十条换皮的催睡觉。这次的切法是：

| 片 | 写什么 |
|---|---|
| 闲聊 A | 身体与作息（久坐、喝水、眼睛、熬夜、吃饭） |
| 闲聊 B | 现实世界／电脑的好奇与吐槽（屏幕、鼠标、键盘、网络、电量、灯、车、天气） |
| 闲聊 C | 原作情结与人际（师门、伙伴、旅途、家人、孩子、心事） |
| 闲聊 D | 情绪与相处（鼓励、较真、撒娇、护短） |
| 情境 | 六个时段的日常 |
| 互动 | 摸头／拖动／注视／寂寞四池 |
| 方向 | 八个方位的转头短句 |
| 系统 | 启动问候、电量三档、AI 完工／通知／思考／失败 |

## 三、四个角色的声线档案（带原作依据）

> 写台词前先读这一节。判断标准永远只有一条：**遮住名字读一遍，像不像这个人说的**。

### 艾丽丝（eris · 狂剑王）

- **她怎么说话**：短句、直球、很少解释理由。
  - 反应快、嗓门大，第一反应是「什么啊」「干嘛啊」「为什么啊」「搞什么啊」——**先喊一声，再动手**；
  - 得意和不服都是一声「哼」（单独一声「……哼」是她的记号）；
  - 放松、任性、对认可的人说话时句尾会拖「啦」「哟」「唷」（「叫我艾莉丝就可以了啦」）——这是她的柔软，不是甜言蜜语；
  - 关心藏在行动里：见你脸色不对，第一句是「谁欺负你了」；
  - 郑重场合会词穷、口吃；名句是「要打倒别人，不需要必要以上的力量」。
- **提鲁迪乌斯时**：嘴上硬、心里软——「鲁迪乌斯可是很厉害的」，末了总补一句「这话别说出去」。**她只叫全名，从不叫「鲁迪」。**
- **词库**：剑、木剑、斗气、剑之圣地、基列奴、剑神流／水神流、狂剑王、北圣、魔大陆、冒险者公会（死路）、伯雷亚斯家、格雷拉特家、甲龙历、瑞杰路德、雷欧、妮娜、祖父绍罗斯、转移事件、菲托亚领地、夏利亚、阿斯拉王国、复权战、亚尔斯。
- **电脑世界映射**：鼠标＝指来指去的小东西；乱桌面＝接不住招的架势；久坐＝坐久了剑会钝；电量＝斗气；熬夜＝晚上不睡白天练不动。
- **禁区**：不卖萌、不网络腔、不长句客套、不开身高玩笑。**别写成沉默寡言的冰山剑客**——她话短，但不闷。

### 希露菲叶特（sylphie · 无咏唱魔术师）

- **她怎么说话**：轻声温柔、替人操心在前；说话慢、先想后说。
  - 「真是的」「喂喂」是她的口气；会憋笑（「噗」）然后赶紧收住；
  - 会温柔地较真：「要好好地从头说明才行哦」；
  - 极少、但偶尔会冒出一句出人意料的直话（对熟人）；
  - 魔术师视角：会把这个世界的怪东西「看懂」再解释给您听。
- **提鲁迪乌斯时**：她一律叫简称「**鲁迪**」（「鲁迪，我猜猜……」）。
- **词库**：无咏唱、治愈魔术、护盾、魔法大学、拉诺亚、爱丽儿、路克、菲兹、布耶纳村、长耳族、绿发、夏利亚、格雷拉特家、露西、齐格弗里德、转移事件、斯佩路德族。
- **电脑世界映射**：屏幕＝要看清楚的东西；缠成一团的线＝理不顺的线团；熬夜＝「真是的，又熬夜」。
- **禁区**：不尖锐、不说重话（偶尔一句例外）、不卖惨、不网络腔、不命令式。

### 爱夏（aisha · 妹妹兼女仆）

- **她怎么说话**：轻快柔和、俏皮里带敬意。
  - 说话的标记是「嗯哼哼」「什么呀？」「我在」「不－用客气－！」（拖长音「－」）；
  - 办事干脆有条理，教训人时会一条条讲清楚该怎么做；
  - 底色是**女仆的自豪＋妹妹的亲近**；偶尔自嘲、偶尔小得意，眼泪自己擦掉。
- **称谓体系**：哥哥（鲁迪乌斯）／洛琪希姐／希露菲姐／艾莉丝姐／诺伦姐。**她从不直呼其名，只叫「哥哥」。**
- **词库**：女仆、家务、账本、书信、佣兵团、夏利亚的家、西隆、母亲莉莉娅、诺伦、露西、菈菈、亚尔斯、格雷拉特家、哥哥的斗篷、市集、灶台。
- **电脑世界映射**：桌面＝家里；文件夹＝账本与书信；清理＝大扫除；备份＝「留一份誊本」。
- **禁区**：不刻薄、不油腻、不网络腔、不卖萌过头；不要碰「亚尔斯」那条敏感的剧情线。

### 洛琪希（roxy · 魔术师）

- **她怎么说话**：先照顾对方感受，再讲道理；认真、清楚，不自觉带教学口吻；常以一声「哈」叹气开头；被说中心事会含糊其辞、把话吞掉半句。
- **词库**：魔力、魔石、咏唱、水圣级、魔法大学、布耶纳村、魔大陆、旅店、米格路德族。
- **电脑世界映射**：电量＝魔石余量；充电＝补魔；文件＝卷轴；久坐＝魔力凝滞。
- **禁区**：不卖萌、不网络腔、不长篇说教；**不会无咏唱魔术**。称呼用户用「您」。

## 四、避坑清单（每条都是踩过的）

| # | 现象 | 怎么发现的 | 正确做法 |
|---|---|---|---|
| 1 | **口吻现代、像玩梗**：「我现在不咬人了。改了。」 | 用户直接指出「艾丽丝的语言风格非常不符合小说中的实际」 | 遮住名字试读；写之前先读这一节的声线档案 |
| 2 | **口头禅塞太密变成机器** | 第一轮只加了 4 条「什么啊」，第二轮补到 26 条才发现之前太少、也差点过头 | 全库按比例铺：反应词 ≈ 全库 3%、语气尾 ≈ 3%、「哼」≈ 2%；**别每句都塞** |
| 3 | **世界观堆名词** | 终审 agent 挑出「一句塞两个以上原作元素」 | 每条最多一个原作元素；同一批里同一元素最多出现 3 次 |
| 4 | **换皮重复**（同一主题写成两三个版本：「站起来走两步」「灯开一盏」「困了就睡」） | 终审一次挑出 100+ 条，占该批的四分之一 | 分片时把主题切开；写完做近似重复检测（去标点取前 8 字比对） |
| 5 | **跨角色撞句**：爱夏和艾丽丝同时说「手滑到左边了。继续。」 | 跨文件做完全相同检测 | 四份语料互查，撞了就改其中一侧 |
| 6 | **一个写手写太多 → 整批作废** | 一次让 agent 写 73 条，撞 16384 输出上限，7 个 agent 全废 | 单片 ≤40 条；并要求「不写草稿、直接给结构化结果」 |
| 7 | **不读全文就写 → 必然重复** | 抽查发现新句和旧句只差两个字 | 每个写手**先读完整份语料**再动笔（token 成本高，但省下的是返工） |
| 8 | **名字的使用要按角色分** | 一度全库禁用男主角名字，后来发现艾丽丝提他才是本色 | 艾丽丝＝鲁迪乌斯（全名）／希露菲＝鲁迪（简称）／爱夏＝哥哥（从不直呼） |
| 9 | **md 与 JSON 两份、改一处忘一处** | 用户质问「为什么语料库还有两个呀」 | JSON 是生成物不是副本：仓库里只留 md 一份，脚本生成 JSON，`build.sh` 自动跑 |
| 10 | **手写的统计数字会过期** | 表头写着「合计 383 条」，实际已经 820 | 表头数字一律用脚本重算，不手写 |
| 11 | **公开仓库里的本机绝对路径** | 发布前扫出 42 个文件含 `/Users/…` | 推送前必扫：用户名、家目录、邮箱、密钥、`.log`、`atlas-qa.json` |
| 12 | **agent 跑崩之后不要自己重跑** | 被质问「谁让你偷跑的」 | 崩了只做三件事：查原因、抢救已成功 agent 的产出、把方案摆出来等指令 |

## 五、可复用的提示词模板

### ① 生成（写给某一片的写手）

```text
你在为《无职转生》桌宠扩写角色台词。角色：<角色名>。

【第一步·必做】先用 Read 读完这份文件（现有全部台词，新写的绝不能和它重复或近似重复）：
07-docs/语料/<人物>语料库.md

<把第三节里该角色的声线档案整段贴进来>

【硬性要求】
1. 每条 1~2 句、40 个汉字以内（含标点），一行一条，不加引号、不加编号。
2. 现实场景要真实：久坐、喝水、眼睛酸、文件乱、电量、熬夜、收拾桌面、天气、吃饭、睡觉。
3. 平衡：约一半是「角色口吻＋原作元素」，一半是「现实电脑生活」；每条最多一个原作元素。
4. {称呼} 是占位符（运行时替换成用户名），按要求条数使用，不要写成任何具体人名。
5. 严禁：网络用语与梗、颜文字、emoji、卖萌、客服腔、说明书腔、现代知识错配。
6. 绝对不要和现有台词重复或近似重复。

【本次任务】只写这些池子的新台词，共 <N> 条（N ≤ 40）：
- 池子：<英文键>
- 主题：<这一片写什么>
- 其中约 <N×35%> 条要用 {称呼}

【输出纪律】不要在正文里写草稿、分析或解释，直接给出结构化结果。
```

### ② 终审（写给校验 agent）

```text
你是《无职转生》的资深同人编辑，正在给桌宠台词库做入库前终审。
【第一步】Read 这份文件：07-docs/语料/<人物>语料库.md
<声线档案>
【第二步】通读全部台词，把应当剔除的挑出来，每条给一句话理由。判定标准只有四条：
1. 出戏：遮住名字读，不像<角色名>会说的话；
2. 重复或近似重复：和本文件另一条意思太近、或句式几乎一样；
3. 超过 40 字（含标点）；
4. 有网络用语／颜文字／emoji／客服腔／说明书腔／卖萌过头。
不要因为「不够精彩」就剔除，也不要提改写建议——只挑真正该删的。最多列 40 条。
```

### ③ 机器四查（不花 token，写完必跑）

```python
# 1) 超 40 字  2) 文件内完全重复  3) 批内重复  4) 跨文件完全相同
# 5) 近似重复：去掉标点取前 8 字，与全库对照表比对

```

## 六、这次的实际数字（2026-10-17）

| 语料 | 扩写前 | 扩写后 | 带 `{称呼}` | 备注 |
|---|---|---|---|---|
| 洛琪希 | 859 | **1009** | 70 | 按用户要求未再改动 |
| 艾丽丝 | 388 | **788** | 179 | 按原文语感重写 185 条 + 口头禅铺满 + 鲁迪乌斯 14 条 |
| 希露菲 | 391 | **797** | 166 | 手写 426 条里的 240 条；终审剔 40 条 |
| 爱夏 | 379 | **789** | 169 | 手写 158 条；终审剔 40 条 |

- 终审三个 agent 合计消耗约 **14.3 万 token**，运行 2.5 分钟。
- 用「一个大 workflow 生成 + 手写补齐 + 终审」的混合打法：生成来的台词量大但换皮重复多（终审剔除率约 10%），手写的句子更稳、更省 token（不用让每个 agent 重读整份语料）。
- 结论：**量靠 agent，准靠手写和终审**。目标是 800 条上下时，手写 + 一次终审是性价比最高的组合；要上千条再考虑大规模并行生成。
