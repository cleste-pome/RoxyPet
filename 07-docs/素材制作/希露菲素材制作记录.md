# 希露菲素材制作记录

依据用户提供的白发时期设定集制作。服装以追加设定图最右侧的无披肩正面造型为准：白色宽袖上衣、深色高领内搭、菱形领饰、编织腰带、棕色短裤、白色长袜、棕色长靴。发型与面部参考白发表情图，保留尖耳、蓝色耳坠、侧分刘海与呆毛。幼年绿发图仅作背景参考，不用于本套造型。

使用内置 image_gen 制作母版，再逐组生成动作；没有使用 CLI 或额外 API。逐组提示词保存在 `06-art-source/sylphie/prompts/`，生成原图在 `sources/`，独立帧在 `frames/`。第一版挥手组误排为一排四列，已重生成为两排两列，并统一为右手挥动；废弃图在 `qa/rejected/` 留档。

用户于 2026-10-18 确认两种比例均保留：修长版为默认（`sylphie-adult`），Q版为另一可选形象（`sylphie-chibi`）。修长版工程保存在 `06-art-source/sylphie/`，Q版工程保存在 `06-art-source/sylphie-chibi/`；各自包含 `sources/` 原图、`prompts/` 提示词与 `frames/` 独立帧。均为无披肩日常装。

每版共 11 组动作：待机、向右跑、向左跑、挥手、跳跃、受挫、等待、思考、检视，以及两组共 16 向视线。跳跃原图最后一格是站姿比例参考，运行时仅使用前五格；每版最终共 73 帧。

沿用已验证的透明轮廓抽帧工具 `03-scripts/pack-eris-atlas.py`（脚本名保留以兼容原工程）。它保留各帧全部可见部件，同组统一缩放，只缩小不放大，脚底对齐并为跳跃设置抬升。输出 3072×4576 的图集，单帧 384×416，运行窗口维持原有 144×156 点。范围与缩放记录在 `02-assets/characters/sylphie-adult/atlas-qa.json`。

```sh
python3 03-scripts/pack-eris-atlas.py 06-art-source/sylphie/sources 02-assets/characters/sylphie-adult
python3 03-scripts/render-pet-preview.py sylphie-adult 05-images/sylphie
python3 03-scripts/pack-eris-atlas.py 06-art-source/sylphie-chibi/sources 02-assets/characters/sylphie-chibi
python3 03-scripts/render-pet-preview.py sylphie-chibi 05-images/sylphie-chibi
bash 03-scripts/build.sh
./Roxy.app/Contents/MacOS/Roxy --self-test
```

抽帧与预览脚本需要 Pillow、numpy。`05-images/sylphie/` 与 `05-images/sylphie-chibi/` 分别保存六种动画预览、全帧检查图及与现有人物的同尺寸对比。

两份人物配置分别使用 `id: sylphie-adult`、`id: sylphie-chibi`，统一使用 `characterID: sylphie`，直接读取已有希露菲语料。本次没有改写语料。角色菜单、菜单栏头像、窗口名称、聊天身份与会话隔离沿用现有多人物机制。

## 2026-10-18 动作与菜单修订

两版跳跃的第一帧和第五帧已按用户要求改为双腿靠拢、轻屈膝的起跳准备与落地缓冲，双手自然放在身体两侧，不再撑地。使用内置 image_gen 定向编辑，最终提示词分别保存为各工程的 `prompts/jumping-revision.md`；替换前原图留在 `qa/rejected/jumping-ground-pose.png`。当前 `sources/jumping.png` 是采用的修订版。

角色菜单按人物身份分组，组间加横线，菜单名统一为「洛琪希」「艾丽丝 · 长发」「艾丽丝 · 短发」「希露菲 · 日常装」「希露菲 · Q版」。用户选定的希露菲修长版排在该人物首位，菜单不显示“默认”字样。
