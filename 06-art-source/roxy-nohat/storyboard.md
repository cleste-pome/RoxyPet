## 形象锁定

蓝色眼睛、蓝色双麻花辫、黑色辫尾结、单根弯曲呆毛；白蓝法师服、胸前黑色交叉带、两道金扣、黑裙和白靴。保持定稿的修长比例、脸型和上色。
不持法杖，不加帽子、披风或新道具。所有姿势保持完整头发、双手、双腿和鞋。

## 九组动作

1. 待机 idle（6帧）：平静睁眼 → 轻呼吸 → 半闭眼 → 闭眼眨眼 → 睁眼 → 回到初始站姿。
2. 向右跑 running-right（8帧）：始终面朝画面右侧，交替迈步，接触、下沉、过渡、腾空各两组，首尾循环。
3. 向左跑 running-left（8帧）：始终面朝画面左侧，同样的八相跑动。
4. 挥手 waving（4帧）：正面抬手 → 轻摆 → 反向轻摆 → 放下；播放可往返。
5. 跳跃 jumping（源图6帧、运行5帧）：下蹲蓄力 → 起跳 → 最高点屈膝 → 下落 → 落地缓冲 → 站立参考。运行前5帧，结束接待机。
6. 受挫 failed（8帧）：肩膀放低 → 低头 → 闭眼轻叹 → 停顿 → 睁眼 → 抬头 → 恢复 → 初始。保持克制表情，无眼泪或脱离人物的特效。
7. 等待 waiting（6帧）：放松站立 → 轻微左看 → 回正 → 轻微右看 → 回正 → 呼吸过渡。
8. 工作 running（6帧）：专注站立 → 手靠近胸前或下巴思考 → 小幅点头 → 保持专注 → 放松 → 初始。此内部状态名为 running，含义为工作进行中。
9. 检视 review（6帧）：目光集中 → 轻微前倾 → 眼睛扫视 → 小幅点头 → 回正 → 初始。

## 十六个视线方向

身体、肩膀和脚保持正面站定，仅转头、抬低下巴和移动视线。始终睁眼。
以画面正上方为0°，顺时针每22.5°一档：
第9行：上、上偏右、右上、右偏上、右、右偏下、右下、下偏右。
第10行：下、下偏左、左下、左偏下、左、左偏上、左上、上偏左。
左右一律指观察者看到的画面左右。

## 接口与组装

运行图集8列×11行，3072×4576 RGBA，单格384×416，逻辑单格192×208。
有效运行帧共73帧；未使用格保持透明。
源分镜每张两行，按从左至右、从上至下读取。角色分离，双辫与四肢不跨格。
组装只做拆帧、等比缩放和定位，不重画或制造中间帧。每动作保持统一比例，非跳跃帧脚底对齐404；跳跃按运行规格抬升。
角色目录使用 roxy-nohat，人物身份使用 roxy，沿用现有语料和会话。
