# 艾丽丝素材制作记录（v2）

本次按用户提供的角色设定图，用内置 image_gen 制作同人桌宠素材。短发保留旅行装设计；长发使用独立的白色露肩上衣、黑色领结、深棕荷叶边裙、白袜、黑色搭扣鞋。语料来自共享目录中已有的 Claude Code 文件，未在美术流程中编写。

## 原工程与修复原因

制作时参考用户保存的 `roxy-creation-package/source-and-qa/decoded/base-transparent.png`、各动作原图及 `frames/`。洛琪希原待机素材为 2172×724 的六帧条带。第一版艾丽丝把整套动作压在单张较小图中，单帧有效分辨率不足；旧打包器只保留最大连通区域，存在丢失独立腿脚的风险。旧加载路径还会把显示帧缩为 192×208，无法利用高清图集。

v2 已替换这条流程：先生成高清角色母版，再分别生成每组动作，保留完整人物，逐组抽帧并输出 Retina 图集。失败的 v1 原图与旧脚本在工作区 `eris-creation-package/v1/` 留档，不作为正式素材。

## 可复现工程

- `07-art-source/eris-short/`、`eris-long/`：母版、11 组动作原图、逐组生成提示词、独立帧。
- `07-art-source/roxy/`：洛琪希的素材工程（母版、动作原图、独立帧、QA）。
- 每组动作原图为 1536×1024，分两排放置 4、6 或 8 帧；跳跃第六帧为站姿参考，不用于运行。
- `03-scripts/pack-eris-atlas.py`：按透明轮廓分组，保留全部可见连通部分，包括独立腿脚；只清除 alpha 小于 16/255 的极淡背景残留。不会只取最大区域，也不会沿等分网格切断人物。
- 同一动作使用一个统一缩放系数，只缩小不放大；脚底对齐，跳跃保留预设抬升。各帧保留透明边距。
- 正式图集为 3072×4576、8 列×11 行、单帧 384×416。`atlas-qa.json` 记录来源尺寸、裁切范围、缩放比例和输出范围。
- Swift 直接裁切原始高清像素作为显示图像；192×208 的独立蒙版只用于鼠标命中判断。

构建、导入和自检命令见 [角色扩展说明](characters.md)。`05-images/eris/` 保存实际图集导出的对比图、动作 GIF 和全帧检查图。原图只用于本地制作与归档，运行桌宠不调用图像生成服务。
